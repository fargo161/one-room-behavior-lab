# Trapstar Package Workspace

This namespace contains the canonical, portable design-and-metadata package(s) for Trapstar.

## Packages

- `packages/room-01/v0.1/` — canonical Room 01 portable design contract package.

The package is intentionally separated from:
- `docs/` (Living Comic runtime authority),
- `schemas/` (Living Comic schema governance),
- `content/` (runtime definition pool),
- `artifacts/` (generated evidence and reified artifacts).

`packages/room-01/v0.1/` stores lightweight machine-readable manifests, catalogs, provenance, QA artifacts, and selected preview references required for tooling and future implementation handoff.
